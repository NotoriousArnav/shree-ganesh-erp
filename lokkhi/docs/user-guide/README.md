# Lokkhi user guide

Lokkhi is where you write bills. It handles two kinds of invoice:

- **Sale** — what a customer bought from you.
- **Purchase** — what you bought from a supplier.

Both use the same editor and the same line rules. The only differences are the
labels (customer or supplier) and which Mushak price is suggested.

Mushak is the inventory app. Lokkhi can look items up in Mushak while you type,
but it never insists on a match.
