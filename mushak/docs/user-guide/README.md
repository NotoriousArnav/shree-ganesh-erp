and the people working at the counter. It explains each screen, what the fields
mean, and what happens when you save.

## What you can and cannot do

Mushak manages products and stock. It does **not** create invoices, take
payments, or file GST returns. Selling something at the counter is recorded as a
**stock movement**, not as a sale document.

If you can see a screen but a button is missing, your account probably lacks the
permission for that action. Ask the shop owner. The
[permissions reference](../reference/permissions.md) lists every action.
